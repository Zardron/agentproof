# Roadmap

## Now (0.1)

Ship a trustworthy CI gate for JS/TS AI-assisted changes: detection, checks, high-value security rules, auth regression, policy thresholds, GitHub Action.

## Next

- More framework adapters
- Smarter monorepo check targeting
- Optional HTML report
- OSV / advisory enrichment for dependency findings

## Later

- Policy packs for agencies and platforms
- Pre-commit / editor integrations
- Performance modes for very large repositories

AgentProof will remain open source, privacy-first, and free of required AI APIs for core analysis.
